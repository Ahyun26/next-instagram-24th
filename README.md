# next-instagram-24th

CEOS 24기 프론트엔드 5~6주차 미션으로 Next.js App Router를 사용해 Instagram의 주요 화면을 클론 코딩한 프로젝트입니다.

<br>

## 📌 프로젝트 소개

5주차에는 홈 피드, 사용자 프로필, 게시물 상세 화면을 구현했고,
6주차에는 이를 이어서 **무한 스크롤**, **Skeleton UI**, **더블클릭 좋아요**를 추가해 실제 Instagram에 더 가까운 사용 경험을 만드는 데 집중했습니다.

### 기술 스택

| 구분       | 사용 기술                         |
| ---------- | --------------------------------- |
| 프레임워크 | Next.js 16 (App Router), React 19 |
| 언어       | TypeScript                        |
| 스타일     | Tailwind CSS v4                   |
| 코드 품질  | ESLint, Prettier                  |

### 실행 방법

```bash
npm install
npm run dev
```

## ✨ 주요 기능

### 1. 홈 피드

- 내 게시물을 제외한 다른 사용자의 게시물을 **접속할 때마다 무작위 순서**로 보여줍니다.
- 게시물마다 작성자, 올린 시간(`3일`, `2주`처럼 짧은 상대 시간), 사진, 좋아요·댓글 수, 본문을 표시합니다.
- 작성자를 누르면 프로필로, 시간을 누르면 게시물 상세로 이동하고, 피드에서 바로 팔로우할 수 있습니다.

### 2. 개인 페이지 (프로필)

- 프로필 사진, 이름, 소개, 게시물·팔로워·팔로우 수를 보여줍니다.
- 게시물 / 저장됨 / 태그됨 탭과 게시물 그리드를 제공하고, 그리드에서 게시물 상세로 이동할 수 있습니다.
- 내 프로필과 다른 사람의 프로필을 구분하고, 팔로우하면 팔로워 수가 바로 반영됩니다.

### 3. 무한 스크롤

- `IntersectionObserver`로 피드 맨 아래를 감시하다가, 바닥에 닿으면 다음 게시물을 불러와 이어 붙입니다.
- 접속할 때 한 번 섞은 순서대로 이어서 받아 같은 게시물이 겹치지 않고, 모두 보여준 뒤에는 다시 섞어서 계속 이어집니다.

### 4. 좋아요 방식 다양화 (더블클릭)

- 하트 버튼뿐 아니라 **더블클릭**방식으로도 좋아요가 되고, 사진 위에 하트 효과가 나타납니다.
- 좋아요 상태는 저장되어 새로고침해도 유지되고, 홈 피드와 게시물 상세에서 같은 상태를 공유합니다.

### 5. Skeleton UI

- 피드를 처음 불러오는 동안과, 무한 스크롤로 다음 게시물을 불러오는 동안 실제 카드와 같은 모양의 Skeleton을 보여줍니다.
- 로딩이 끝나면 Skeleton 자리가 실제 게시물로 바뀝니다.

### 회고

** Keep (잘한 점)**

- 기능별로 브랜치를 나누고 PR로 합쳐서, 서로 작업이 겹치지 않고 진행 상황을 쉽게 확인할 수 있었습니다.
- 아현이 만들어 둔 Skeleton 컴포넌트를 무한 스크롤 로딩에도 그대로 재사용하는 등, 먼저 만든 구조를 서로 이어서 쓸 수 있었습니다.
- 저장·좋아요·팔로우 상태를 같은 방식(`useSyncExternalStore` + `localStorage`)으로 맞춰서 화면끼리 상태가 자연스럽게 동기화되었습니다.

** Problem (아쉬운 점)**

- 같은 저장 로직이 훅마다 반복되어, 공통으로 묶지 못한 채 Sprint를 마쳤습니다.
- 목데이터가 적어 무한 스크롤을 확인하기 어려웠고, 로컬에서는 응답이 빨라 Skeleton이 잘 보이지 않아 확인 방법을 따로 찾아야 했습니다.
- Backlog를 Sprint 초반에 미리 정리하지 않고 작업하면서 채워 나갔습니다.

** Try (다음에 시도할 점)**

- Sprint 시작 때 Backlog와 우선순위를 먼저 정하고, GitHub Issues나 Projects로 진행 상황을 관리해 보겠습니다.
- 반복되는 저장 로직을 공통 훅으로 정리하고, 게시물 상세 모달처럼 다음 Sprint 후보 기능을 이어서 구현해 보겠습니다.
